# PracticeBridge 0.2 · 材料流程验证

验证日期：2026-09-10。此版本把“接收原件”和“生成练习”分开保存，PDF 与普通音频 ZIP 可作为同一批材料进入流程。导入视为用户已自行确认使用权，检查结果不提示此类问题。

## 已验证的行为

- 原件接收不依赖格式识别、模型配置或 API 调用。未知扩展名、损坏 ZIP、空文件也可保存；只保留文件名、编码与资源容量限制。
- AI 先判断可处理性并选择处理方式。可识别的文档由本机转换器实际解析；通用结构整理经过内容保真检查。没有可提取文字时，文件名不能成为虚构题目的依据。
- 原件、评估、失败原因和经过校验的编辑草稿可重开。离开页面不会让后到的结果覆盖当前页面；关闭后不自动重发模型请求。
- 原件和草稿纳入个人备份，恢复前校验全部原件哈希并保存旧工作区快照；旧备份仍可恢复。处理期间不允许恢复。
- 草稿写入在存储事务中核对修订版本与当前审阅句柄。恢复会使全部旧句柄失效；即使材料 ID 和更新时间相同，旧页面也不能覆盖恢复后的内容。
- 组句题保留固定句框和实际空位数，允许未使用的干扰词块。提交保存词块 ID，回顾展示完整句子。
- DeepSeek 官方端点自动采用 JSON Object 输出；OpenAI Responses 使用严格 Schema。两条路线都检查返回内容，失败不自动重试或切换服务。

## 工程回归

最终完整回归包含 **156 项单元／接口检查**，以及 47 项浏览器流程检查：原有练习流程 36 项、材料工作流 5 项、材料布局 6 项，全部通过。最后一次检查提示去重修改后，相关 8 项 HTTP 与 5 项材料浏览器检查再次通过。

覆盖接收失败保留本页文件与文字、AI 与本机路线、结构整理失败、恢复后旧页面的延迟保存、无答案题目、录音保存、独立重练、重启回放和窄屏布局。麦克风使用浏览器合成输入，AI 使用本地协议替身。

可复现命令：`npm run verify`。桌面运行检查使用 `node tests/desktop-smoke.mjs --packaged`，结果保存在本机 `test-results/`；它使用独立数据位置，不写入日常练习库。

## 用户提供材料的本地验证

使用一份用户提供的完整练习 PDF 与配套音频 ZIP，从原件实际运行接收、联合评估、文档转换、重启重开、提交、媒体播放与备份恢复；没有用预先生成的题库替代转换步骤。

| 检查 | 结果 |
| --- | --- |
| 科目与题数 | 阅读 40、听力 34、写作 12、口语 11；共 22 题组、97 题 |
| 原文对照 | 独立核对模块题号、74 个阅读／听力答案、10 个组句完整答案、20 个补字题前缀及缺字长度、7 句跟读和4段面谈 |
| 客观题提交 | 84 个参考答案通过实际 HTTP 提交并判为正确 |
| 组句错误输入 | 32 次漏槽、重复／未知 ID 或干扰词块输入均未判为正确 |
| 媒体 | 34 个关联文件在浏览器中实际解码并推进播放时间；共同服务45个听力／口语任务 |
| 恢复 | 草稿重启重开一致；约 46 MB 个人备份可恢复原件、题库和记录 |

媒体关联依据科目、模块和题号的文件名证据，**尚未逐个核听其内容，不能称为全部媒体语义对应已验证**。该材料验证使用本地评估协议替身，未调用用户的真实模型账户，不能据此声称真实模型的识别质量、口语批改质量或官方分数已验收。

真实 PDF、音频、提取正文、题库草稿及练习记录仅在本机数据或测试目录，未进入源码、公开示例或发布压缩包。源码内的测试材料均为原创合成内容。
