# 首版实现范围

依据 2026-09-10“学习系统改造总结”的最新方案：独立、默认空题库、本地优先的练习软件，用户提供材料与模型。AI 助手和练习界面共享受限的数据接口；AI 不直接写题库，也不控制计时与判分。

## 代码来源

本目录从空目录开始独立编写。`src/`、`public/`、`desktop/`、`scripts/`、`tests/`、文档和自编演示材料均为本轮新建。没有复制旧商业客户端的运行程序、字节码、题库接口、题库媒体或私人作答；旧隔离版保留在原位置。

借鉴了先前项目已经明确的产品要求：反馈归属固定 Attempt，重练与重新批改分开，没有答案不记零分，口语反馈区分转写证据与声音证据，后台工作不替换正在阅读的回顾。

## 模块

- `src/package.mjs`：练习包规范、媒体与 ZIP 校验、内容标识、导出。
- `src/importer.mjs`：文字提取、标记模板、常见普通文档、AI 草稿来源校对。
- `src/store.mjs`：原子状态、媒体存储、题目快照、客观判分。
- `src/server.mjs`：只对本机开放的受限接口、录音、续做、任务队列、备份恢复。
- `src/models.mjs`：用户模型配置、内存密钥、JSON 输出、引用核验、文字反馈。
- `src/codex.mjs`：官方本机 CLI 版本检测；推理入口明确关闭。
- `public/`：概览、题库、导入校对、七类基础题型、回顾、分析、助手和模型设置。
- `desktop/main.cjs`：独立 Electron 窗口、媒体权限、关闭前保存。

## 首版的验收含义

源码可运行、便携样本可启动，已有明确输入路线能够走完“导入—作答—保存—回顾—重练—导出”流程。自动化使用原创文档、合成音频、模拟麦克风与本地模型协议样本。

这一结论不等于对任意题库导入准确率、真人口语批改质量、真实模型账户兼容性、官方评分或跨电脑安装的验证。它们需要后续选定实际材料和账户分别验收。

本轮咨询了原方案聊天一次，集中询问 CLI 支持范围及纵向验收缺口。按建议补了普通 Word 文档、同名不同目录媒体、局部答案表及一次表单修正的验证，没有为了样本增加全部官方题型或 CLI 通用 Agent 权限。
