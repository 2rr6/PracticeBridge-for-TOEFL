# PracticeBridge 0.4 · 输入格式与数据约定

用户无需准备 JSON。直接选择原文件或粘贴文字，先保存到材料库；AI 评估或本机转换后，会生成软件使用的统一模板。下面的字段说明供制作可交换题包、开发转换器或检查结构化草稿时参考。

新版模板使用 `examSets → sections → modules → taskIds` 组织机考流程，实际题目仍保存在 `groups[].questions`。12 个任务族复用原有 7 个基础作答类型，支持正文内缺字、固定句框、文档块、任务说明音频阶段与分开保存的原稿。详见 [机考模板](机考模板.md)。

接收原件、评估、生成草稿、确认加入题库是不同步骤。接收成功说明原文件已经保存；只有草稿通过结构与媒体校验、并经确认后才成为正式题库。AI 与本机转换器使用同一套字段和校验路线，用户无需手写模板。旧基础题包和旧模型响应仍兼容，不会因此自动获得原材料没有的模块、版式或来源证明。

## 12 个任务族与 7 种答案类型

| 任务族 `taskKind` | 基础 `type` | 需要保留的结构 |
| --- | --- | --- |
| `complete_words` | `fill_blank` | 完整正文、逐空位 ID、缺字范围与固定前后文字 |
| `read_daily` | `single_choice` | 通知、邮件、社交帖或普通材料，与题目分开 |
| `read_academic` | `single_choice` | 文章、题目，可附有明确来源的原句选择／插句位置 |
| `listen_response` | `single_choice` | 当前音频与回应选项 |
| `listen_conversation` | `single_choice` | 共用对话音频与有序题目 |
| `listen_announcement` | `single_choice` | 共用通知音频与有序题目 |
| `listen_talk` | `single_choice` | 共用讲座音频与有序题目 |
| `build_sentence` | `sentence_order` | 固定句框、实际空槽、词块 ID 与干扰词块 |
| `write_email` | `email` | 情境、任务点、收件人和主题 |
| `academic_discussion` | `discussion` | 教师问题和各学生的发言 |
| `listen_repeat` | `listen_repeat` | 刺激音频、准确目标原句与学生录音 |
| `interview` | `interview` | 面谈问题音频与学生录音 |

`taskKind` 负责材料布局和流程，`type` 负责答案形状。阅读、听力共用单选基础类型，不表示它们共用一个题面。选句与插句仍是保存单一候选 ID 的 `single_choice`，不是多选题。

## 常见文档

本机常见文档转换器可从文字 PDF、DOCX、TXT / Markdown 提取以下结构；不要求添加项目专用的 `@` 标记：

```text
Title: My practice
Reading: Campus garden
Passage:
The garden opens at nine. Mira waters the plants on Tuesdays.
Questions:
1. When does the garden open?
A. At eight.
B. At nine.
Answer key: 1 B

Speaking: Interview
Audio: speaking/interview.wav
Preparation time: 15 seconds
Response time: 45 seconds
Questions:
1. Describe a place where you like to study.
```

这是受限的常见练习文档解析器，不是通用文档理解保证：

- 科目标题如 `Reading: ...`、`Listening: ...`、`Speaking: Interview`。未知的口语任务不会被猜成面谈。
- 题号支持 `1.`、`Q1:` 等明确形式；选择题使用 `A.` / `B.` 选项。
- 每个题组可以重新从 1 开始，答案表只关联所属题组。相同题组中出现重复题号会提示歧义。
- `Answer key: 1 B`，或在标题后逐行写 `1. B`。缺少答案则保留为不计分，不能由 AI 补成原题答案。
- `Audio: ...` 出现在题目之前时属于整组；题目之后需明确写 `Question audio:` 或 `Group audio:`，或在校对表单中选择。
- 来源计时需带 `seconds` / `minutes` 单位。题包中缺失的时限仍保留 unknown；运行时另用版本化的软件练习默认值，统一显示倒计时，不把默认值写回来源。
- PDF 来源使用提取页码；Word 来源使用段落编号，不能据此宣称 Word 页码。扫描 PDF 暂不支持；多栏阅读顺序、页眉、自动列表编号可能需要人工整理。

导入材料文件夹时，顶层文件夹名字会去掉，内部子目录保留。例如选择 `my-materials` 文件夹，其中 `speaking/interview.wav` 的引用就是 `speaking/interview.wav`。不同子目录里的同名文件不会被合并。拖入重复的同名文件会要求处理，不能按顺序猜测。

更复杂的文字可以主动选择 AI 整理。AI 只能输出草稿；来源不支持的改写、答案或媒体关联会被清除或提示。程序校验不能证明全部语义正确。

## 规范练习包

制作可交换的原生题包时，ZIP 根目录放 `practicebridge.json`，媒体使用安全的相对路径。也可同时选择一份 JSON 和对应媒体。普通文档或音频 ZIP 不需要此清单，可以与 PDF 一起接收到材料库。AI 评估之后再选择转换方式，规范包也可仅在本机识别。

```text
practicebridge.json
audio/interview.wav
audio/listening.wav
images/diagram.png
```

规范按 `schemaVersion` 分派：[v1 规范与模型协议](practicebridge.schema.json)、[v2 正式题包规范](practicebridge.v2.schema.json)。[自编完整示例](../public/examples/practicebridge.json) 使用 v1，包含全部 7 类基础作答组件。候选编译产生 v2，逐题保留 `sourcePositionV1` 原始题位，可附 `candidateLineageV1`，包级 `coverageV1` 标记材料、考试与选择的完整性。v2 输入先经过不补默认值、不转换类型、不删除未知字段的 Ajv 校验，再检查规范化结果；ZIP 导出也检查 v2 规范。v1 的兼容投影与模型协议保持原样，旧题库原件不会自动迁移。

包需要稳定的 `id` 和作者填写的 `version`，组与题目也要有唯一 ID。含 `examSets` 的新模板同时声明 `examContractVersion: 1` 和所需 `minReaderVersion`（v1 模板为 `"0.3.0"`，v2 候选编译为 `"0.5.0"`）。不支持的执行版本或原生交互会明确报错。内容版本、机考合同版本和会话版本分别记录，不混用。

| 字段 | 含义 |
| --- | --- |
| `groups[].section` | reading / listening / speaking / writing |
| `groups[].passage` | 本组共享文字材料 |
| `examSets` | 套题、科目与模块；模块用 `taskIds` 引用本包题组，不复制题目 |
| `groups[].taskKind` | 12 个任务族之一；与本组科目及底层作答类型匹配 |
| `groups[].presentation` | 每屏题目数、作答/复盘可见性，以及文档块、邮件或讨论角色布局；规范文档块为 heading / paragraph / table |
| `groups[].inlineBlanks` | 正文中可核实的缺字位置；UTF-16 半开区间，答案模式为 missing_letters，保留固定前后文字 |
| `groups[].directions` / `modules[].instructions` | 任务说明与模块说明；文字、明确音频、来源及内容是否已核实，不与题目刺激音频混用 |
| `groups[].timing` / `modules[].timing` | 明确计时作用域、数字秒数或 null、依据；不将模块时限复制到每题 |
| `groups[].transcript` / `questions[].transcript` | 题目附带的纯文字原稿，与学生录音转写分开；听说作答不自动显示，PRACTICE 可主动打开原稿辅助 |
| `audio` / `image` | 本组或本题的明确相对媒体路径；不支持远程 URL |
| `questions[].type` | single_choice / fill_blank / sentence_order / email / discussion / interview / listen_repeat |
| `questions[].options` | 带稳定 `id` 的选项或词块 |
| `questions[].answer` | 单选选项 ID；补词正确文本或允许答案列表；组句词块 ID 序列；跟读的准确目标原句；其他情况可为 null |
| `questions[].source` | 原文档、页码或段落等来源说明，不能拿它当作跟读原句 |
| `questions[].localNumber` / `ordinalInTask` | 原文题号（可空）与任务内显示顺序；永久 ID 不随显示编号改变 |
| `questions[].interaction` | 阅读的 sentence_select / sentence_insert；正文范围或四个零长插入位置、候选 ID 与可选待插入原句；保持单一 ID 答案 |
| `questions[].sentenceFrame` | 组句题可选的固定句框；每一组连续下划线表示一个词块空位，固定单词和标点保持原样 |
| `questions[].answerSlots` | 与句框一起提供的空位数，不能多于词块数；允许保留不参与答案的干扰词块 |
| `timeLimitSeconds` / `prepareSeconds` | 保留的旧逐题秒数字段；0.3 以冻结计划的 timing 和本轮 preset 计时，不把旧逐题默认值累加为模块时长 |
| `rights` | 可留空的用户附加来源文字，不影响导入 |

扩展字段可以省略。除明确可空的子值外，正式元数据对象不使用 null。严格模型协议中的可选 null 会先由模型适配器剥离，再送入同一校验器；未知字段和不支持的交互不会被悄悄丢弃。

例如正文为 `con__tion` 时，两个格子只输入 `di`，固定的 `con` 和 `tion` 仍来自正文。`inlineBlanks` 保存空位及其前缀的 UTF-16 位置，校验正文片段和哈希；不能先拿到 `condition` 再倒造空位。缺少可核对位置时保留复核问题，不把完整单词当成缺字答案。

组句的答案保存词块 ID，空槽可保留为空字符串，不能用文字是否相同判断词块身份。材料附有部分可用题目但没有答案键时，可以形成未评分草稿；不会由 AI 解题补成“原题答案”。

## 说明音频与计时依据

`group.audio` 是共用刺激材料，`question.audio` 是当前题音频；Directions 和模块 instructions 有各自的说明字段。音频相关字段只引用确实收到的相对路径。媒体文件头和实际解码可以证明文件类型与可播放性，不能证明其内容与某道题语义相符。

对于已识别的完整试题文档，本机适配器可以按音频文件名中的科目、模块、任务类型和完整题号范围唯一关联 Directions。该关联保存 `basis: "filename"`、`verifiedContent: false`；若有两个冲突候选，不自动选一个。看到了配套文件名，不代表 AI 听过录音。模块说明音频在 Begin 前播放；TEST 需播完，PRACTICE 可主动确认跳过并留下辅助标记。任务说明播放器与模块说明入口的最终验收状态见 [机考验证](机考验证.md)。

新计时对象使用 `scope: module | task | question | none`，题组也可 `inherit_module`；`durationSeconds` 为明确秒数或 null，`basis` 为 `document | user | preset | unknown`。时限与准备时间必须来自相应材料或本轮用户设置。不能把多个空位各自的旧默认秒数累加为整段时限。

本轮 `preset` 默认为材料时限加软件默认，也可填写阅读每模块、听力每题、组句整个任务、跟读每题和面谈每题的秒数。没有填写的类别使用材料时限，材料缺失则用练习默认。面谈无论何种设置均最多 45 秒；旧 untimed 和 0 值在新策略下恢复默认倒计时。听说题缺少题目音频时列出缺项并阻止开始。

单选匹配选项 ID；组句按空位匹配词块 ID 顺序，未提供句框时沿用全部词块排序。补词会忽略两端空白和大小写，标点不同仍视为不同；如果需要多个可接受答案，请明确列出。缺少标准答案不记为错误，不进入客观正确率。

## 限制与失败行为

PDF / DOCX 单文件不超过 64 MB；其他文件 / 媒体 / 录音单文件不超过 25 MB；ZIP 不超过 80 MB；一次上传原始文件合计不超过 80 MB；ZIP 展开后不超过 160 MB、最多 1200 个条目。单包最多 1000 道题。个人完整备份另限压缩后 160 MB、解压后 160 MB，恢复入口沿用同一上限。

接收阶段不检查扩展名、文件内容或 ZIP 清单，原件保存后才进入评估。文件名不能包含路径跳转、绝对路径或控制字符。ZIP 处理阶段会检查重复成员、符号链接、类型伪装和解压资源大小；失败仍保留原 ZIP。不执行包内脚本。音频与图像会检查文件特征；能否正常播放仍须实际解码验证。

材料原件、AI 评估和草稿独立于正式题库持久保存。审阅页面过期或退出应用后，可从材料库重新打开草稿，无需重传原件。确认加入题库时再次校验；失败不产生半套正式题库。相同内容重复导入返回已有题库；修改内容后的导入由新的 `contentHash` 与 `libraryId` 区分，不覆盖旧库、旧会话或旧作答快照。题包的 `version` 仍由作者填写。个人备份包含尚未处理的原件与草稿；恢复不会自动重发 AI 请求。

## 旧题库与供应商格式

旧 v1 题包的基础结构继续接受导入。新界面为它建立运行时计划，保留原题库 JSON 和内容哈希；普通旧填空与明确正文缺字任务的兼容补验见 [机考验证](机考验证.md)。对先前本机完整文档转换器生成、来源与 ID 符合约定的旧模块题库，保留在材料库中的 PDF／音频 ZIP 可用于只读补充 Directions 和有 PDF 布局依据的讨论分块；原件缺失或证据不唯一时保留已有文字。已开始的 v2 会话不会被后来的投影变化改写，新建练习才采用新投影。

本项目只读观察过一份飞马供应更新包与先前保存的结构快照。观察结果是媒体资料加内部题库容器，未证实有公开可导入的 JSON 源模板；本软件不声称可以直接读取该内部容器。这里公开的是 PracticeBridge 自有模板，用户无需准备或取得供应商私有库才能使用。

## 导出和个人备份

题库导出仅包含原题包和原包明确引用的媒体；不混入个人录音、作答、反馈或密钥，也不会为了运行时兼容投影而改写旧包。个人完整备份是另一个入口，包含材料原件、草稿、学习记录和本地媒体，能够重建旧库补充说明音频的引用。恢复前校验内容关系、媒体哈希、题目快照、模块提交回执与判分；通过后替换工作区，并保存恢复前快照。

0.3 会话使用 `sessionVersion: 2`，创建时固定 `planSnapshot`。草稿可以继续修改；完成模块时一次保存其中全部题目的作答，已封存记录不能被后来草稿覆盖。恢复或重启会更换写入令牌，旧页面不能覆盖当前状态。API 字段见 [集成合同](CONTRACT.md)。

当前为单用户原子 JSON 存储。请通过应用的备份功能迁移数据，不要在运行中手动编辑状态文件。此前版本的验证范围与数字保留在 [首版验证结果](首版验证结果.md) 和 [0.2 材料流程验证](材料流程验证.md)。
